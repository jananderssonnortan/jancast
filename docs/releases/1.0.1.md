## Luftbro 1.0.1

- **Signed updates.** Luftbro installs an update only when it is signed with a key that is kept off GitHub, so access to the releases alone can't push an update to your Mac. The download itself carries a build attestation from GitHub, which `gh attestation verify` checks.
- **ffmpeg 8.1.3 and Python 3.14.10,** with their security fixes, and up-to-date Python packages.
